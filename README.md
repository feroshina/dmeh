# dmeh
downloading media easier handler, a bash script and c++ command to make downloading and managing youtube playlists, videos more easier

personal tool, expected to work on Linux  
didnt test for Windows, but code may run on it  
works on Android via termux, still need to automate the process  

c++ version currently only for linux

# project goals
future spotify-dlp integration  
optional automatic history archiver
better/more flags like ´-v/--verbose --noconfirm´

# dependencies
bash, ytdlp (python-ytdlp depending on distribution), g++
